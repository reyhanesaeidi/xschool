خانه 👩‍🎓 من کیم؟ 🔎 یادگیری HTML

از کجا شروع کنیم؟

HTML دنیای ساده و کاربردیه. فقط با یاد گرفتن تگ‌ها و کمی دانش مقدماتی پایتون (که در این آموزش کامل توضیحش می‌دم) می‌تونید یک صفحه وب رو روی سیستم خودتون اجرا کنید. قبل از هر چیز، باید بدونیم لوکال یعنی چی؟
لوکال، یا همون آدرس http://127.0.0.1:5000، محیطیه که وب‌سایت شما فقط روی کامپیوتر خودتون اجرا می‌شه و بقیه بهش دسترسی ندارن. برای داشتن یه وب‌سایت واقعی که همه ببینن، باید از هاست و سرور استفاده کنید (که توی آموزش‌های بعدی دقیق‌تر یاد می‌گیریم). اما این آموزش فقط برای بالا آوردن وب‌سایت توی محیط لوکال شماست.

قدم اول

توی این آموزش قصد داریم دو صفحه وب بالا بیاریم؛ پس تو قدم اول باید دو تا کد HTML ساده بنویسیم:
  • صفحه اصلی (Home)
  • صفحه معرفی (About)

کد HTML برای صفحه اصلی (Home) این کد: یک صفحه ساده با یک عنوان و یک پاراگراف خوش‌آمدگویی ایجاد می‌کنه. 
<!DOCTYPE html>
<html lang="fa" dir="rtl">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>صفحه اصلی</title>
</head>
<body>
    <h1>به صفحه اصلی خوش آمدید!</h1>
    <p>اینجا دنیای سادگی و شروع یادگیری HTML است.</p>
    <a>href="/about">درباره من</a>
</body>
</html>

کد HTML برای صفحه معرفی (About):این کد، یک صفحه ساده برای معرفی شما با یک تیتر و یک توضیح کوتاه است. 

<!DOCTYPE html>
<html lang="fa" dir="rtl">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>درباره من</title>
</head>
<body>
    <h1>درباره من</h1>
    <p>من علاقه‌مند به یادگیری و ساخت صفحات وب هستم.</p>
    <a>href="/">خانه</a>
</body>
</html>
  • <DOCTYPE html!>: به مرورگر می‌گه که این یک صفحه HTML هست.
  • <html lang=fa dir=rtl>: کل صفحه رو در بر می‌گیره. lang fa یعنی زبان فارسیه و dir rtl یعنی متن از راست به چپ نوشته می‌شه.
  • <head>: اطلاعاتی درباره صفحه می‌ده که معمولاً نمایش داده نمی‌شن (مثل عنوان صفحه).
  • <meta charset=UTF-8>: تنظیم کاراکترها برای پشتیبانی از زبان فارسی.
  • <meta name=viewport content=width=device-width, initial-scale=1.0>: برای نمایش بهتر در دستگاه‌های مختلف (مثل موبایل).
  • <title: متنی که در تب مرورگر نشون داده می‌شه.
  • <body>: محتوای اصلی صفحه رو شامل می‌شه که کاربر می‌بینه.
  • <h1>: تیتر اصلی صفحه (بزرگترین عنوان).
  • <p>: یک پاراگراف متن.
  • <a>: ساخت لینک به صفحات دیگر
شما باید یک پوشه با عنوان templates ایجاد کنید و این دو فایل با پسوند html. داخل اون ذخیره کنید. فقط توجه داشته باشین پوشه‌ها و مسیرها برای ما مهمه پس حتما با همین اسم پوشه ایجاد کنید.

قدم دوم

برای اینکه بتونیم صفحات HTML مختلفی رو در قالب یک وب‌سایت نمایش بدیم، معمولاً از یک فریم‌ورک وب مثل Flask در پایتون استفاده می‌کنیم. Flask به ما اجازه می‌ده که مسیرهای مختلف (URL ها) رو تعریف کنیم و برای هر مسیر، مشخص کنیم که چه محتوایی (کد HTML) نمایش داده بشه. در این مرحله، یک قطعه کد پایتون می‌نویسیم که صفحات HTML ما رو فراخوانی و نمایش می‌ده. این کد از کتابخانه Flask برای ساخت یک برنامه وب ساده استفاده می‌کنه. 
from flask import Flask, render_template

#Create instance of Flask App
app = Flask(__name__)

#Create instance of Flask App
app = Flask(__name__)

#Define Route and Contant of that page
@app.route("/")
def home():
    return render_template("home.html")

#Define 2nd Route and Content
@app.route("/about")
def about():
    return render_template("about.html")
  • from flask import Flask, render_template: این خط کتابخانه‌های لازم را از Flask وارد می‌کند.
    • Flask برای ساخت برنامه وب استفاده می‌شود.
    • Flask برای نمایش فایل‌های HTML به کار می‌رود.
  • app = Flask(__name__): یک نمونه از برنامه Flask ساخته می‌شود. Flask__name__ به Flask کمک می‌کند مسیر فایل‌ها و منابع برنامه را پیدا کند.
  • @app.route این خط یک مسیر یا Route برای صفحه اصلی سایت تعریف می‌کند.
  • def home: این تابع زمانی اجرا می‌شود که کاربر وارد صفحه اصلی شود.
  • return render_template("home.html") فایل home.html را از پوشه templates می‌خواند و نمایش می‌دهد.
شما باید این کد با پسوند ipynb. خارج از پوشه templates ایجاد کنید. همانطور که قبلا گفتم مسیرها مهمه پس لطفا دقت کنید.
