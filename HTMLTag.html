آموزش انواع تگ‌های HTML

HTML زبانی است که برای ساختاردهی به صفحات وب استفاده می‌شود. در HTML همه‌چیز با تگ‌ها ساخته می‌شود. تگ‌ها به مرورگر می‌گویند هر بخش از صفحه چیست؛ مثلاً عنوان، پاراگراف، تصویر، لینک، جدول و غیره.

تگ HTML چیست؟

تگ HTML یک دستور است که داخل علامت‌های <> نوشته می‌شود. بیشتر تگ‌ها به صورت جفتی هستند؛ یعنی یک تگ باز و یک تگ بسته دارند. مثلا: 

<p>این یک پاراگراف است</p>

در این مثال:

  • <p> تگ باز است
  • <p/> تگ بسته است
  • متن بین آن‌ها محتوای پاراگراف است.

دسته‌بندی تگ‌های HTML

تگ‌های HTML را می‌توان به چند گروه اصلی تقسیم کرد:

1. تگ‌های ساختاری

این تگ‌ها اسکلت اصلی صفحه را می‌سازند.

  • <HTML> : کل صفحه HTML را مشخص می‌کند
  • <head> : بخش اطلاعات صفحه
  • <body> : محتوای قابل‌نمایش صفحه

2. تگ‌های عنوان

برای نوشتن تیترها و سرتیترها استفاده می‌شوند.

<h1> تا <h6> برای عنوان‌ها استفاده می‌شوند. h1 بزرگ‌ترین و مهم‌ترین عنوان است و h6 کوچک‌ترین آن است.

3. تگ پاراگراف

برای نوشتن متن‌های عادی و توضیحات استفاده می‌شود.

4. تگ‌های لینک

برای ساخت لینک به صفحات دیگر یا بخش‌های مختلف سایت استفاده می‌شوند.

<a href="https://example.com">رفتن به سایت</a>

ویژگی href آدرس مقصد لینک را مشخص می‌کند.

5. تگ‌های تصویر

برای نمایش عکس در صفحه استفاده می‌شوند.

<img src="image.jpg" alt="تصویر نمونه">

ویژگی‌های مهم:

  • src مسیر تصویر
  • alt متن جایگزین تصویر

6. تگ‌های لیست

برای نمایش مطالب به صورت فهرست استفاده می‌شوند.

لیست مرتب: <ol>

لیست نامرتب: <ul>

آیتم‌های لیست: <li>

7. تگ‌های جدول

برای نمایش اطلاعات به صورت جدول استفاده می‌شوند.

  • <table> : جدول
  • <tr> : ردیف
  • <th> : عنوان ستون
  • <td> : داده‌های جدول

8. تگ‌های فرم

برای گرفتن اطلاعات از کاربر استفاده می‌شوند.

  • <form>
  • <input>
  • <label>
  • <textarea>
  • <button>

9. تگ‌های معنایی

این تگ‌ها به ساختار و معنی بهتر صفحه کمک می‌کنند.

  • <header> : بخش بالای صفحه
  • <nav> : منوی سایت
  • <main> : محتوای اصلی
  • <section> : بخش‌بندی محتوا
  • <article> : یک مقاله یا محتوای مستقل
  • <footer> : بخش پایانی صفحه

تگ‌های خالی یا بدون بسته

بعضی از تگ‌ها نیاز به تگ بسته ندارند. به این‌ها تگ‌های خالی گفته می‌شود.

نمونه‌ها:

  • <br> : رفتن به خط بعد
  • <hr> : خط افقی
  • <img> : نمایش تصویر
  • <input> : دریافت ورودی از کاربر

ویژگی‌های تگ‌ها

تگ‌ها می‌توانند ویژگی یا attribute داشته باشند. ویژگی‌ها اطلاعات بیشتری درباره تگ می‌دهند.

مثال:

<a href="https://example.com" target="_blank">لینک</a>

در این مثال:

  • href آدرس لینک است
  • target="_blank" باعث می‌شود لینک در صفحه جدید باز شود

جمع‌بندی

تگ‌های HTML پایه و اساس ساخت صفحات وب هستند. با یادگیری انواع تگ‌ها می‌توانی متن، تصویر، لینک، فرم، جدول و ساختار کامل یک وب‌سایت را ایجاد کنی. اگر HTML را خوب یاد بگیری، یادگیری CSS و JavaScript هم برایت خیلی ساده‌تر می‌شود.
