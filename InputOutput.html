خانه 👩‍🎓 من کیم؟ 🔎 یادگیری HTML

قراره چیکار کنیم؟

از این به بعد، یادگیری رو با چند تا تمرین عملی ادامه میدیم. توی این تمرین، قراره حقوق پایه و ساعات اضافه کاری افراد رو به عنوان ورودی بگیریم، بعدش حقوق اضافه کاری رو حساب کنیم و نتیجه رو نمایش بدیم. هدف اصلی اینه که با کار کردن با ورودی‌ها، خروجی‌ها و توابع، مهارت‌هامون رو تقویت کنیم. پس بریم که شروع کنیم.

قدم اول - چه طوری ورودی بگیریم؟

همانطور که قبلا تو آموزش تگ‌ها ( اینجا ) یاد گرفتیم، برای دریافت ورودی باید از تگ <Input> استفاده کنیم. به قطعه کد زیر دقت کنید: 
<input type="text" id="base_salary" placeholder="حقوق پایه">
<input type="text" id="overtime_hours" placeholder="ساعت اضافه کاری">
  • این قطعه کد دو فیلد ورودی متن ایجاد می‌کند.
  • type=text مشخص می‌کند که کاربر می‌تواند متن را در آن وارد کند.
  • id=base_salary یک شناسه منحصربه‌فرد برای این فیلد است که می‌توان از آن برای ارجاع به این فیلد در کدهای دیگر (مثلاً جاوا اسکریپت برای پردازش) استفاده کرد.
  • placeholder متنی راهنما است که درون فیلد نمایش داده می‌شود و به کاربر می‌گوید چه اطلاعاتی باید وارد کند. این متن زمانی که کاربر شروع به تایپ می‌کند، ناپدید می‌شود.
تا اینجا ما حقوق پایه و تعداد ساعات اضافه کاری دریافت کردیم الان باید میزان اضافه حقوق را محاسبه کنیم.

قدم دوم - چه طوری محاسبات لازم انجام بدیم؟

برای محاسبه اضافه کاری با حقوق پایه، ابتدا باید دستمزد هر ساعت کار را محاسبه کنید (حقوق پایه تقسیم بر تعداد ساعت اجباری در طی یکماه که ما در اینجا 192 در نظر می‌گیریم.). در این صورت اگر ۴۰ درصد از دستمزد هر ساعت کار معمولی را به دستمزد یک ساعت کار اضافه کنید، مبلغ هر ساعت اضافه کاری را محاسبه خواهید کرد. به عنوان مثال اگر برای هر ساعت ۱۰۰ هزار تومان دستمزد دریافت کنید، میزان دستمزد شما برای یک ساعت اضافه کار ۱۴۰ هزار تومان خواهد بود. اما چه طوری توی HTML پیاده‌سازی کنیم؟
برای پیاده سازی این موارد نیاز به شناخت از توابع داریم. توابع مثل دستورالعمل‌های آماده یا ماشین‌های کوچک هستند. شما یک ورودی (مثلاً حقوق پایه و ساعت اضافه کاری) به آن‌ها می‌دهید و آن‌ها یک کار مشخص را انجام می‌دهند و یک خروجی (مثلاً کل حقوق) به شما برمی‌گردانند. به قطعه کد زیر دقت کنید: 
 <script>
        function calculateOvertime() {
        const baseInput = document.getElementById("base_salary").value;
        const hoursInput = document.getElementById("overtime_hours").value;

        const regularHours = 192; // فرض بر اینکه 192 ساعت کارکرد عادی در ماه است
        const overtimeRate = 1.4; // نرخ اضافه کاری 1.4 برابر حقوق عادی
        const regularHourlyRate = baseSalary / regularHours;
        const overtimePay = regularHourlyRate * overtimeHours * overtimeRate;
        document.getElementById("overtime_pay").innerText = "Overtime Pay: " + Number(overtimePay.toFixed(0)).toLocaleString('en-US');
    }
    </script>
این قطعه کد جاوا اسکریپت یک تابع به نام calculateOvertime تعریف می‌کند که برای محاسبه و نمایش حقوق اضافه کاری طراحی شده است. بیایید بخش‌های مختلف آن را بررسی کنیم:
  • { ... }()function calculateOvertime : این خط تابع اصلی را تعریف می‌کند. هر کدی که داخل این آکولادها قرار دارد، زمانی اجرا می‌شود که تابع calculateOvertime فراخوانی شود.
  • دو خط بعدی، مقادیری را که کاربر در فیلدهای ورودی با شناسه‌های base_salary (حقوق پایه) و overtime_hours (ساعت اضافه کاری) وارد کرده است، می‌خوانند.
  • دو خط بعدی مقادیر ثابت مورد نیاز برای حل مسئله نیاز است، تعریف می‌شوند.
  • دو خط بعدی محاسبات لازم که در بالا توضیح دادیم انجام می‌شوند.
  • خط آخر هم مسئول نمایش نتیجه محاسبه شده حقوق اضافه کاری در صفحه وب است.

برای نمایش خروجی هم فقط یه به قطعه کد کوتاه نیاز:
